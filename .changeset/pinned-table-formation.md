Add `<fv-table-pinned>` — a horizontal-scroll formation for `<fv-table>` on narrow viewports: the inner table keeps a minimum width (`data-min-width`) and the wrapper scrolls, while the first `data-pin` columns (default 2, e.g. rank + team) stick to the left edge and ride over the columns scrolling beneath. Component in locker-room, stylesheet in kitroom's global styles.
